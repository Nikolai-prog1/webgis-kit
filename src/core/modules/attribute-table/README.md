# Attribute table

Layer table buttons open reusable bottom panels. Columns come from describe, metadata controls labels/order/visibility. Pages contain 100 rows; sorting, text search, row highlight and UTF-8 BOM CSV are supported. CSV is capped at 10,000 rows and protects formula-like cells.

Options: Layer `table: true` and `fields` metadata. Enable the Cities table in the demo; no separate toolbar entry.

See [module documentation](../../../../docs/modules/attribute-table.md) and the demo configuration for a working instance. Setup returns a disposable when listeners, layers or panels need teardown.
