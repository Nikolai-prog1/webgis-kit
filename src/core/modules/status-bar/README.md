# Status

Shows cursor coordinates in configured systems and an OpenLayers scale line. CRS labels, decimal precision and axis order come from configuration.

Options: `statusBar.coordinates` contains CRS codes; `scaleLine` enables the scale. The demo shows WGS84 and Web Mercator.

See [module documentation](../../../../docs/modules/status-bar.md) and the demo configuration for a working instance. Setup returns a disposable when listeners, layers or panels need teardown.
