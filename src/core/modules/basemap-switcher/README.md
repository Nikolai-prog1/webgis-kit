# Base maps

Radio selection, optional none and shared opacity. Selection and opacity use the application storage prefix. XYZ/OSM sources enable anonymous cross-origin images for export.

Options: `basemaps.items`, `default`, `allowNone`, `opacityControl`

See [module documentation](../../../../docs/modules/basemap-switcher.md) and the demo configuration for a working instance. Setup returns a disposable when listeners, layers or panels need teardown.
