# Markers

Places a pin and coordinate card in all configured systems, with copy and remove controls. Enter on a focused map places a center marker while the tool is active. Clear removes all pins/cards.

Options: Add `marker` to `toolbar`; configure systems in `crs`. Coordinate entry shares the marker service.

See [module documentation](../../../../docs/modules/marker.md) and the demo configuration for a working instance. Setup returns a disposable when listeners, layers or panels need teardown.
