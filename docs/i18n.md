# Localization

Core dictionaries are flat `en.json` and `bg.json` files. `t(key, params)` substitutes `{name}` and selects `_one`/`_other` using `Intl.PluralRules` when `count` is supplied. Tests require matching key sets and verify literal core keys. Deployment labels use `localized(value)` with current language, English, then first-value fallback.

Locale selection is URL `?lang=` first, prefixed storage next, then `app.locale`; only configured `app.locales` are accepted. Switching the header selector saves the language and reloads with that query parameter. `messages` in app JSON overrides selected keys. Data values such as country names remain the source's values. Numeric/date/boolean table display follows the selected language; `format: id` preserves identifiers without numeric grouping.
